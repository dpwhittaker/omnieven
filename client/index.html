Omni needs a server you run

          
Omni is a framework: the glasses show whatever your own server renders, and every app is a small file on that server that hot-reloads onto your glasses. Nothing is hosted for you — set up a server once (about ten minutes), then paste its address into the Connect tab.

          
Any machine your phone can reach works: a small VPS, a home box, or a laptop on Tailscale. Node.js 22.18+ or Docker.
